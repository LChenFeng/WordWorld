# 文字世界

一个全由文字组成的2D侧视开放世界游戏，目前还在不断完善游戏框架和机制，玩法较少

### 系统要求（最新版本）

| 名            | 版本                       |
|--------------|--------------------------|
| python       | 3.10+（`match`改`if`可3.8+） |
| pygame       | 2.6.1                    |
| numpy        | 2.1.3                    |
| pywin32      | 310                      |
| perlin-noise | 1.14                     |

右侧`releases`中可下载游戏及源码

## 获取方块

由于目前没有创造模式物品栏，大部分方块需要通过代码获取

#### 步骤

打开`main.py`，找到`load_player()`函数，
`player.knap.add(...)`即为设定初始背包物品的语句  
语法：`player.knap.add(Items(方块id, [数量]))`  
方块id在`Data/json/blocks/`下的2个文件中，数量默认为1

## 操作教程

#### UI界面：

| 键位              | 操作   |
|-----------------|------|
| W/S/A/D/鼠标滚轮/箭头 | 切换选项 |
| 空格/回车           | 确定   |

#### 游戏界面：

| 键位       | 操作        |
|----------|-----------|
| A/D      | 移动        |
| W/S      | 飞行（仅创造模式） |
| 空格       | 跳跃        |
| Esc      | 退出并保存     |
| E        | 背包        |
| 鼠标左键     | 挖掘方块      |
| 鼠标右键     | 放置方块/使用   |
| 鼠标滚轮/0-9 | 切换手持物品    |
